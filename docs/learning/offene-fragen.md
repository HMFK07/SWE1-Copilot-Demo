# Offene Fragen und Annahmen

- **Projekt:** Mobilitäts-App
- **Stand:** Context Slice 1
- **Status:** Arbeitsdokument der Studierenden

Dieses Dokument dient dazu, offene Fragen, widersprüchliche Annahmen und Entscheidungen festzuhalten. Es enthält bewusst keine vorgegebenen Lösungen.

| ID | Quelle (z. B. S01) | Frage oder Annahme | Status | Entscheidung / Begründung |
|---|---|---|---|---|
| OF-01 | S01 | Welche Streckendaten sollten für weitere Fahrten erhalten bleiben? | offen | – |
| OF-02 | S01 | Wie kann man aktuelle Verbindungsdaten von wiederverwendeten Eingaben unterscheiden? | offen | – |
| OF-03 | S01 | Welche Information belegt für den Fahrgast einen erfolgreichen Ticketkauf? | offen | – |

## Arbeitsregel

Eine Annahme ist noch keine abgestimmte Anforderung. Halten Sie abweichende Optionen und Entscheidungen nachvollziehbar fest; ergänzen Sie Datum bzw. Übung, wenn Sie eine Frage klären.
