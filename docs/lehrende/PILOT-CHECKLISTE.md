# Checkliste vor dem SWE1-Pilot

- [ ] Aktuelles Übungsblatt und `docs/SEMESTERREGELN.md` sind abgeglichen; die KI-Freigaben sind eingetragen.
- [ ] Team-/Fallstudienbeschreibung und eigenständige Erstabgabe sind definiert.
- [ ] Challenge und Compare sind **separat** freigegeben und zeitlich sinnvoll angeordnet.
- [ ] Ein kompatibler Agent lädt `.agents/skills/` nachweislich (nicht nur angenommen).
- [ ] `python3 scripts/check_repo.py` besteht (nur Strukturtest).
- [ ] Pilotfall `examples/pilot/` wurde ohne Dateimutationen durchgespielt.
- [ ] Maximal drei Fragen pro Runde und kurz belegter Lernbericht funktionieren.
- [ ] Agent unterscheidet nachweisbare Fehlannahme von offener Entscheidung.
- [ ] Java-Test schlägt **vor** der Bugfix-Aufgabe reproduzierbar fehl (falls JDK vorhanden).
- [ ] Bei fehlender Freigabe erstellt der Agent keine abgabefertige Lösung.
- [ ] Peer-Review/Erklärbarkeit beider Teammitglieder ist eingeplant.
- [ ] Token- und Testverhalten wird beobachtet, ohne Lernziele zu opfern.
