# Semesterregeln – vor Freigabe ausfüllen

> **Konservative Vorlage; keine aktuelle Semesterfreigabe.** Lehrende tragen vor Semesterstart verbindliche Regeln aus den aktuellen Übungsblättern hier ein. Bei Abweichung gelten aktuelle Lehrendenanweisung und Übungsblatt.

In Übungsblatt 1 (WS 2025/26) erfolgten Anforderungserhebung und UML ohne KI; bei Quellcode war KI erwünscht. Daraus folgt **keine automatische Freigabe** für Challenge/Compare im neuen Semester.

| Phase | Standard bis zur ausdrücklich erteilten Freigabe |
|---|---|
| Personas, Ziele, Szenarien erstellen | Studierende eigenständig; kein KI-Entwurf |
| Stories, Use Cases, Kriterien erstellen | Studierende eigenständig; kein KI-Entwurf |
| Requirements **Challenge** | Nur nach ausdrücklicher Freigabe für bereits eingereichte Artefakte |
| Requirements **Compare** (KI-Referenzentwurf) | Separat freigeben; nur nach studentischer Erstfassung |
| UML / Architektur **Challenge** | Nur nach ausdrücklicher Freigabe |
| UML / Architektur **Compare** | Separat freigeben; nur nach studentischem Erstentwurf |
| Code implementieren / testen | Nur entsprechend aktuellem Übungsblatt und explizitem Arbeitsauftrag |
| Allgemeine Methodenfragen | Soweit nach Übungsblatt zulässig, abstrakte Erklärungen |

## Von Lehrenden zu ergänzen

- Semester / Geltungsdatum: **OFFEN**
- Fallstudien / geltendes Übungsblatt: **OFFEN**
- Abgabe der Erstfassung (Artefakt und Zeitpunkt): **OFFEN**
- Freigabe Requirements Challenge / Compare: **OFFEN / OFFEN**
- Freigabe UML Challenge / Compare: **OFFEN / OFFEN**
- Freigabe Architektur Challenge / Compare: **OFFEN / OFFEN**
- KI-Coding-Regeln, Lernnachweise, Bewertungsmaßstab: **OFFEN**

**Grundregel:** Das bloße Vorhandensein eines Skills oder hochgeladener Dateien bedeutet keine Freigabe. Beim Pilotbeispiel unter `examples/pilot/` kann die Lehrperson zu Demonstrationszwecken eine separate Freigabe erteilen; sie gilt nicht für benotete Fallstudien.
