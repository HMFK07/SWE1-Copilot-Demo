# UML im Repository

Die fachliche Modellierung erfolgt zuerst durch die Studierenden. PlantUML (`.puml`) eignet sich für Versionskontrolle und Analyse, ist aber **keine Pflicht**; bei komplexen Objektflüssen, Pins oder Komponenten-Konnektoren sind grafische UML-Tools zulässig.

`uml-review` unterscheidet: (1) syntaktisch renderbar, (2) UML-semantisch plausibel, (3) zu den Requirements passend. Eine erfolgreiche Renderprüfung beantwortet nur (1). Konkrete KI-Modellprüfungen sind erst nach Freigabe gemäß `docs/SEMESTERREGELN.md` erlaubt.
